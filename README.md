# Avito Candidate Generation: Hyperlocal & Microcategory-Routed Hybrid Retrieval

Современный многостадийный пайплайн генерации кандидатов для Avito Search, основанный на **маршрутизации по микрокатегориям (Microcategory Routing)**, **мультимодальном поиске (Field-Aware Lexical + Dense E5)** и **гиперлокальном каскадном ранжировании (Local-First Geo-Cascade)**.

---

## 1. Контекст и почему старый пайплайн не работал

Предыдущий baseline (`BM25` + `generic E5` + `Two-Tower v1` $\to$ `RRF` $\to$ `CatBoost`) на публичном лидерборде показал всего:
$$\text{Recall@50} = 0.303828$$

### Причина нерепрезентативности старой валидации:
* Старая валидация проводилась на изолированном подмножестве из ~34k позитивных товаров (positive-only corpus).
* В реальном соревновательном бенчмарке поиск ведется по **полному корпусу из 189 212 товаров**.
* Из-за отсутствия явного учета локации глобальный лексический и плотный поиск по огромной стране находил релевантные по тексту объявления из Владивостока, Сочи и Новосибирска, заполняя ими топ-50 и вытесняя локальные релевантные товары пользователя на 150–250 места.

---

## 2. Ключевые открытия и физическая специфика платформы

При переходе к канонической валидации на полном бенчмарк-корпусе (**5 347 поисковых контекстов** и **189 212 товаров**) были выявлены фундаментальные свойства предметной области:

1. **Маршрутизация по микрокатегориям (Microcategory Routing):**
   * Top-5 микрокатегорий, предсказанных гибридной моделью, дают **92.85% positive containment** (в 93 из 100 случаев истинный товар лежит внутри предсказанных микрокатегорий).
   * При этом корпус поиска сжимается со **189 212** до **~5 863 товаров (сокращение в 32 раза)**.

2. **Гиперлокальная специфика Авито (Hyperlocal Reality):**
   * В **99.98%** случаев товар строго совпадает по категории (`item_category_id == search_category`).
   * В **84.16%** случаев релевантный товар находится в том же самом городе (`item_location_id == search_location_id`).
   * **97.28%** всех взаимодействий происходят в радиусе **до 30 км** от пользователя (медиана — **4.3 км**).

## 3. Финальная архитектура пайплайна

```text
Поисковый запрос (search_query, location_id, category, params)
                          │
                          ▼
        [1. Microcategory Routing (Hybrid Model)]
  (Exact Posterior + TF-IDF SGDClassifier -> Top-5 микрокатегорий)
                          │
                          ▼
            Корпус кандидатов (~5 800 товаров)
                          │
         ┌────────────────┴────────────────┐
         ▼                                 ▼
[2. Routed Field-Aware Lexical]     [3. Routed Dense E5]
• Char TF-IDF (3-5 n-grams, k=1000) • multilingual-e5-base (k=1000)
• Word TF-IDF (1-2 n-grams, k=1000) • Global E5 fallback (k=300)
• Title+Params Char (k=1000)
• Global Lexical fallback (k=300)
         │                                 │
         └────────────────┬────────────────┘
                          ▼
             [4. Weighted RRF Fusion (c=60.0)]
           Пул кандидатов глубиной k=1000
           (Oracle Union Coverage@1000 = 87.06%)
                          │
                          ▼
   [5. Local-First Hyperlocal Geo-Cascade Ranking]
• Tier 1: Тот же город (location_id) и категория (top-50 локальных)
• Tier 2: Ближайшие города (dist <= 50 км, exp geo-decay)
• Tier 3: Область / регион (dist > 50 км)
• Tier 4: Глобальная страховка (fallback)
                          │
                          ▼
              Top-50 уникальных товаров
                          │
                          ▼
                      answer.csv
```

## 4. Результаты канонической валидации (5 347 queries, 189k items)

Все метрики измерены на честном 5-фолдовом разбиении (80% train знания, 20% held-out валидация) без утечек данных.

### 4.1. Качество маршрутизации по микрокатегориям

| Модель маршрутизации | Top-1 Cont | Top-3 Cont | Top-5 Cont | Top-10 Cont | Средний размер корпуса |
|---|---:|---:|---:|---:|---:|
| Exact Posterior | 0.7065 | 0.7955 | 0.8116 | 0.8227 | ~4,200 |
| TF-IDF Classifier (Word + Char) | 0.8185 | 0.9341 | 0.9552 | 0.9748 | ~5,800 |
| **Hybrid (Selected Top-5)** | **0.8030** | **0.9139** | **0.9285** | **0.9379** | **5,863.4** (p95: 12,624) |

*Срез по новым запросам (Unseen Query, N=794):*
* Exact Posterior: `Top-5 = 0.0957` (схлопывается без обобщения).
* Generalizing Classifier / Hybrid: `Top-5 = 0.8829` (высокая способность к обобщению).

---

### 4.2. Лексический поиск: глобальный vs маршрутизированный

Проверена монотонность: $\text{Recall@50} \le \text{Recall@100} \le \text{Recall@200} \le \text{Recall@500} \le \text{Recall@1000}$.

| Метод ретривера | Recall@50 | Recall@100 | Recall@200 | Recall@500 | Recall@1000 |
|---|---:|---:|---:|---:|---:|
| Global Word (Title) | 0.1999 | 0.2735 | 0.3553 | 0.4778 | 0.5549 |
| Global Char (Title) | 0.2225 | 0.3073 | 0.4111 | 0.5758 | 0.6826 |
| **Routed Word (Title)** | **0.2081** | **0.2877** | **0.3783** | **0.5290** | **0.6405** |
| **Routed Char (Title)** | **0.2316** | **0.3241** | **0.4374** | **0.6156** | **0.7331** |
| Routed Title+Params | 0.2002 | 0.2882 | 0.3983 | 0.5743 | 0.7039 |
| **Best Lexical Fusion** | **0.2343** | **0.3262** | **0.4418** | **0.6168** | **0.7526** |

*Вывод:* Маршрутизация дает устойчивый прирост по всем лексическим ветвям (до **+8.6 п.п.** на $k=1000$).

### 4.5. Прогрессия качества финального ранжирования (Recall@50)

| Пайплайн ранжирования | Принцип ранжирования | Recall@50 | Прирост |
|---|---|---:|---:|
| **Old Baseline Champion** | Global BM25 + E5 + TwoTower $\to$ RRF $\to$ CatBoost | **0.3038** | — |
| **New Routed Candidate Baseline** | Routed Lexical + Routed E5 $\to$ Naive RRF-60 | **0.2638** | -4.0 п.п. (шум чужих регионов) |

## 5. Независимая валидация файла answer.csv

Финальный артефакт `answer.csv` проходит полный контракт соревновательной верификации:
* **Количество строк**: ровно **2 452** строки с ответами;
* **Колонки**: строго `query_id,answer`;
* **Количество товаров на запрос**: ровно **50 уникальных ID**;
* **Валидность ID**: 100% товаров присутствуют в `benchmark_items.parquet`;
* **Дубликаты**: 0 дубликатов;
* **Формат чисел**: все ID сохранены как строковые токены без научной нотации;
* **SHA-256**: `6f6edcb9ef8d997c33de4547a4e7b72bd3cf064974fdbbc25a8aa054ad247418`

### Сравнение с предыдущим сабмишном (0.303828):
* **Среднее пересечение (mean overlap)**: всего **15.3 товара из 50**;
* **Изменение top-1 кандидата**: у **87.4%** запросов top-1 товар полностью изменился;
* **Существенное обновление (> 25 новых товаров)**: у **84.7%** запросов.

## 6. Воспроизводимость и запуск

```bash
# 1. Установка окружения
uv sync

# 2. Запуск тестов и проверка типизации
uv run pytest
uv run pyright
uv run ruff check src tests

# 3. Воспроизведение валидации маршрутизации и ретриверов
uv run python scripts/evaluate_routing.py
uv run python scripts/evaluate_retrieval_and_fusion.py

# 4. Генерация финального сабмишна на бенчмарке
uv run python scripts/generate_geo_cascade_submission.py
```
