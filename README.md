# Avito Candidate Generation: Hyperlocal & Microcategory-Routed Hybrid Retrieval

Современный многостадийный пайплайн генерации кандидатов для Avito Search, основанный на **маршрутизации по микрокатегориям ($K=10$)**, **мультимодальном поиске (Field-Aware Lexical + Dense E5 с глобальным фоллбэком)** и **гиперлокальном каскадном ранжировании (Local-First Geo-Cascade с поддержкой Wildcard Category 0)**.

## 2. Разгадка Generalization Gap: почему оффлайн переоценивал скор

Был проведен математический аудит распределения соревновательного бенчмарка (`benchmark_queries.parquet`, $N=2\,452$) против канонической валидации ($N=5\,347$):

1. **Аномалия Category 0 (прямая потеря ~6.3 п.п. на лидерборде):**
   * В оффлайн-валидации запросов с `search_category == 0` было всего **$0.02\%$**.
   * В соревновательном бенчмарке таких запросов **$9.05\%$ ($222$ запроса)**.
   * Старый бейзлайн умножал скор на штраф `cat_mult = 0.001`, если категория товара не совпадает с `search_category`. Так как товаров с категорией 0 в каталоге Авито не существует (в обучающей выборке по ним кликали категорию 114), старый пайплайн получал **$\text{Recall@50} = 0.0000$** на всех 222 запросах бенчмарка.
   * **Решение (Wildcard Category 0):** при `search_category == 0` штраф категории не применяется (`cat_mult = 1.0`), что возвращает срез к $\sim 70\%$ качества.
   $$\Delta \text{Official Recall@50} \approx 0.0905 \times 0.70 \approx \mathbf{+6.33 \text{ п.п.}}$$

2. **Сдвиг новизны запросов (Seen vs Unseen Queries):**
   * В оффлайн-валидации **$85.15\%$** запросов были виденными в обучающей выборке (**Seen**), и лишь **$14.85\%$** — новыми (**Unseen**).
   * В официальном бенчмарке **$65.05\%$ запросов — полностью новые (UNSEEN)**.
   * На срезе Seen бейзлайн показывал **$0.7150$**, а на срезе Unseen проседал до **$0.6455$** (разрыв **$-6.95$ п.п.**).
   * Взвешенный скор на реальном распределении бенчмарка в точности предсказывает наблюдаемый официальный результат:
     $$0.3495 \times 0.7150 + 0.6505 \times 0.6455 = \mathbf{0.6698} \quad \xrightarrow{\text{с учетом Cat 0 (9.05%)}} \quad \mathbf{0.6464}!$$

Все эксперименты проводились в строгом соответствии с фальсифицируемым протоколом в независимых OS-процессах:

| **H2** | Обучение CatBoost ranker на кандидатах пула | Pointwise 5-fold OOF CatBoost с нормализованными признаками и гео | CatBoost R@50: **0.3532** vs Geo-Cascade: **0.5308** ($\Delta = \mathbf{-17.76 \text{ п.п.}}$) | **KILLED**: pointwise Logloss разрушает жесткую иерархию локации, пропуская дальний шум в топ-50 |
| **H3** | Аналитическое гео-ранжирование и семантический гейтинг | Сравнение 9 стратегий (No Geo, SameLoc 5/15/30, Semantic Gating) | No Geo: **0.2586** (-44.6 п.п.), Semantic Gating: **0.5731** (-13.2 п.п.), SameLoc=30: **0.7047** | **ACCEPTED**: жесткий локальный приоритет критичен, семантический гейтинг убит из-за коротких запросов |

| **H6** | Глобальный фоллбэк поверх маршрутизации | Добавление Global E5 + Word + Char на глубине 300 | Инкрементальное покрытие пула: $\mathbf{+4.29 \text{ п.п.}}$ ($0.8252 \to \mathbf{0.8681}$) | **ACCEPTED**: надежная страховка от промахов классификатора |

## 4. Архитектура чемпионского пайплайна (Champion Architecture)

```text
Поисковый запрос (search_query, location_id, category, params)
                          │
                          ▼
        [1. Microcategory Routing (Hybrid Model)]
  (Exact Posterior + Generalizing TF-IDF Classifier -> Top-10 микрокатегорий)
  (Покрытие на новых запросах = 92.07%, медианный корпус = 6 173 товара)
                          │
                          ▼
          ┌────────────────┴────────────────┐
          ▼                                 ▼
[2. Routed Field-Aware Lexical]     [3. Routed Dense E5]
• Char TF-IDF (3-5 n-grams, k=1000) • multilingual-e5-base (k=1000)
• Word TF-IDF (1-2 n-grams, k=1000) • Global Dense E5 Fallback (k=300)
• Title+Params Char (k=1000)
• Global Lexical Fallback (k=300)
          │                                 │
          └────────────────┬────────────────┘
                           ▼
              [4. Weighted RRF Fusion (c=60.0)]
            Пул кандидатов глубиной k=1000
            (Покрытие пула Oracle Coverage@1000 = 87.06%)
                           │
                           ▼
    [5. Local-First Hyperlocal Geo-Cascade Ranking]
• Wildcard Category 0 Fix: поисковая категория 0 не штрафуется (открывает доступ ко всем товарам).
• Tier 1: Тот же город (item_location_id == search_location_id) & валидная категория.
• Tier 2: Ближайшие города (dist <= 50 км, exp geo-decay) & валидная категория.
• Tier 3: Область / регион (dist > 50 км) & валидная категория.
• Tier 4: Глобальная страховка (fallback).
                           │
                           ▼
               Top-50 уникальных товаров
                           │
                           ▼
                       answer.csv
```

## 6. Воспроизводимость и запуск

Пайплайн поддерживает полную воспроизводимость через единый CLI:

```bash
# 1. Установка зависимостей
uv sync

# 2. Проверка качества кода и тестов (make ci)
make ci

# 3. Полный прогон генерации чемпионского сабмишна (answer.csv)
uv run avito answer --output answer.csv

# 4. Независимая соревновательная верификация файла
uv run avito verify --scope release --submission answer.csv --queries data/benchmark_queries.parquet --items data/benchmark_items.parquet
```
